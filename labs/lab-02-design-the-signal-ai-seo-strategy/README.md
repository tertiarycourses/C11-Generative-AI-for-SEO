# Lab 2: Design the SIGNAL AI SEO Strategy

**Mapping:** LO1 · A6 · K1 · K6  
**Objective:** Create an organisation-level AI SEO strategy and governed workflow  
**Deliverable:** 90-day SIGNAL strategy and governance page  
**Primary source:** https://developers.google.com/search/docs/fundamentals/using-gen-ai-content

## Scenario

Google permits appropriate use of generative AI but warns that scaled, low-value content created mainly to manipulate rankings can violate spam policies.

EcoDesk has one marketer and one subject-matter expert. Management wants faster content production without publishing generic or unsupported environmental claims.

## Training assumptions and guardrails

- The 90-day budget is S$6,000 and eight staff-days.
- Only public and synthetic data may enter general-purpose AI tools.
- Publishing, outreach and technical directives require named human approval.
- The initial agentic workflow is read-only and recommendation-only.

## Questions

1. What outcome should SEO create beyond traffic?
2. Which information advantage can EcoDesk credibly own?
3. Which tasks are suitable for copilot, workflow or agent mode?
4. Which risks require a stop rule or human approval?

## Detailed step-by-step procedure

### Step 1: Define outcomes

Translate the business goal into audience, conversion and quality outcomes with baselines.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 2: Apply SIGNAL

Complete Search intent, Information advantage, Generative workflow, Network authority, Accessibility and Learning loop.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 3: Select priorities

Choose a small topic cluster, core landing page and supporting media based on the audit.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 4: Design the workflow

Map inputs, prompts, tools, reviewer, publishing gate, log and rollback for each task.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 5: Classify risk

Place each AI action into low, medium or high risk and specify permissions.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 6: Write prompt policy

Define allowed data, sources, fact checking, copyright, disclosure and prohibited claims.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 7: Build roadmap

Sequence foundations, pilot, measurement and expansion across 90 days.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 8: Publish strategy page

Add a concise strategy summary to the sample website and verify navigation and mobile display.

**Checkpoint:** Save the evidence, file or decision produced before continuing.
