# EcoDesk Singapore — Shared SEO Activity Website

Live site: https://tertiarycourses.github.io/C11-Generative-AI-for-SEO/

This is the **one shared fictional website used by all ten course activities**. Learners audit and progressively improve the same pages, content, metadata, structured data, lead magnet, enquiry funnel and WhatsApp-style assistant.

## Run locally

```bash
python3 -m http.server 8000 --directory activities/ecodesk-demo-website
```

Open `http://localhost:8000/`.

## Lead-generation architecture

- Strong intent-led home-page pitch and repeated action prompts.
- Free workplace buying guide delivered after a browser-only demo form.
- Separate product and answer-first article pages for keyword and internal-link work.
- Client-side WhatsApp-style assistant with pre-approved fictional answers.
- Optional course-support WhatsApp hand-off, clearly labelled as external.
- No personal information is transmitted by the demo forms.

## SEO implementation

- Unique titles, descriptions and canonical URLs.
- Static crawler-readable copy, FAQ answers and product information.
- Organization, WebSite, FAQPage, ItemList, Product and Article JSON-LD matching visible content.
- Open Graph metadata, semantic headings, descriptive alt text and accessible navigation.
- `robots.txt`, `sitemap.xml`, noindex lead-delivery pages and responsive layouts.

## Activity progression

1. Audit the current baseline.
2. Design the SIGNAL strategy and governance rules.
3. Generate and validate the keyword universe.
4. Map keyword clusters to these pages and briefs.
5. Improve the answer-first article using a claim ledger.
6. Create image, video and LinkedIn distribution assets.
7. Review and implement metadata, internal links and JSON-LD.
8. Improve answer units for AI Overview eligibility without promises.
9. Analyse synthetic Search Console and GA4 evidence.
10. Design a governed agentic monitoring workflow.
