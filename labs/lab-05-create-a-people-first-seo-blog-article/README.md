# Lab 5: Create a People-First SEO Blog Article

**Mapping:** LO3 · A5 · K7 · K10  
**Objective:** Generate and edit a grounded long-form article  
**Deliverable:** Verified, edited SEO blog article with claim ledger  
**Primary source:** https://developers.google.com/search/docs/fundamentals/creating-helpful-content

## Scenario

Helpful content is created primarily to benefit people; AI-assisted content still needs originality, accuracy, transparent authorship and appropriate expertise.

EcoDesk wants a practical guide for Singapore SME office managers who need credible sustainability actions without exaggerated claims.

## Training assumptions and guardrails

- All examples are illustrative and must be labelled when not source-backed.
- The article must not claim certification, guaranteed savings or environmental impact without evidence.
- The author is an EcoDesk workplace sustainability adviser with a transparent bio.
- Target length is a guideline; completeness and clarity win.

## Questions

1. What is the reader's main decision?
2. Which claims need sources or qualification?
3. What first-party experience can make the article non-commodity?
4. Which internal links continue the user journey?

## Detailed step-by-step procedure

### Step 1: Lock the brief

Confirm audience, intent, angle, evidence and conversion before drafting.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 2: Build claim ledger

List every factual or quantitative claim with source, owner and approved wording.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 3: Generate outline

Ask for answer-first sections, comparison, checklist, examples and FAQ; remove filler headings.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 4: Draft in sections

Generate one section at a time using only approved evidence and visible uncertainty markers.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 5: Expert edit

Add specific operational examples, remove generic phrasing and test whether advice is actionable.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 6: SEO edit

Refine title, description, headings, internal links, image plan and concise answer blocks.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 7: Run adversarial QA

Ask a separate review prompt to find unsupported claims, contradictions, duplication and manipulation risk.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 8: Publish and inspect

Create the static blog page, validate links and read it on mobile.

**Checkpoint:** Save the evidence, file or decision produced before continuing.
