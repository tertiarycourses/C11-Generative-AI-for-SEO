# Lab 6: Generate Image, Video and LinkedIn Assets

**Mapping:** LO4 · A3 · A5 · K3 · K5  
**Objective:** Create multimodal SEO assets and an ethical off-page distribution plan  
**Deliverable:** Multimodal SEO asset pack and ethical LinkedIn distribution post  
**Primary source:** https://developers.google.com/search/docs/appearance/google-images

## Scenario

Images and video should be relevant, accessible and technically efficient. Social distribution can earn discovery and links, but manipulative link schemes remain prohibited.

EcoDesk will launch the new guide with one original hero visual, a 45-second explainer and a LinkedIn post for SME operations leaders.

## Training assumptions and guardrails

- Generated visuals may not include logos, copyrighted characters or unsupported certifications.
- The video is a concept storyboard; learners do not need paid generation tools.
- The LinkedIn post must not ask for reciprocal or paid links.
- All media files use synthetic examples and are clearly labelled.

## Questions

1. What job does each media asset perform?
2. What visual inaccuracies or rights risks must the prompt prevent?
3. What belongs in alt text versus a caption?
4. Why would another professional voluntarily reference the article?

## Detailed step-by-step procedure

### Step 1: Define media intent

Map one visual and one video to specific article sections and search/user needs.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 2: Write image prompt

Specify subject, composition, accuracy constraints, prohibited elements, crop zones and output use.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 3: Review concept

Check authenticity, text artefacts, representation, copyright and environmental-claim risk.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 4: Prepare image SEO

Write descriptive filename, dimensions, compression plan, alt text and surrounding caption.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 5: Storyboard video

Create six scenes with narration, on-screen text, b-roll and evidence references.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 6: Create video SEO

Draft title, description, transcript, thumbnail brief, chapters and valid VideoObject fields.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 7: Draft LinkedIn post

Run Templates 1-4 in the prompt pack: repurpose the article, write a first-person post, adapt the announcement to the guide launch and plan a five-post week. Lead with a practitioner insight, cite one useful example, link transparently and invite informed discussion.

**Checkpoint:** Save the evidence, file or decision produced before continuing.

### Step 8: Publish library

Add static media cards, transcript and metadata examples to the sample site.

**Checkpoint:** Save the evidence, file or decision produced before continuing.
